# FastVideoDown

Free online video downloader for 1,000+ sites. Paste any video link, pick a quality, and save the video in HD or MP3 — no sign-up, no watermark.

**Live site:** https://fastvideodown.jo3.org (Cloudflare Pages; API on Cloady)

## How it works

- **Frontend:** a single static `index.html` (inline CSS/JS, no external requests) plus one SEO landing page per supported site (generated by `scripts/gen-sites.py` from `sites.txt`).
- **Engine:** [yt-dlp](https://github.com/yt-dlp/yt-dlp) running inside two Netlify Functions:
  - `netlify/functions/formats/` — resolves a link into title, thumbnail, and every available quality (video with sound / video-only / audio-only), including each format's direct download URL.
  - `netlify/functions/download/` — resolves a chosen format to its direct CDN URL, and streams small files (audio and clips under 5.5 MB) through the server so the browser is forced to save them instead of playing them.
- **Speed:** the formats response already carries every direct link, so the Download button opens the file instantly. A short in-memory cache (5 min, warm containers only) makes repeat lookups of a viral link instant.
- **IP rotation ready:** set the `YTDLP_PROXY` env var (one proxy URL or a comma-separated list) and each request picks a random proxy. No proxy is configured by default.

## Deploy (Netlify)

Connect this repo to Netlify. The build command regenerates the SEO pages and fetches the yt-dlp binaries (they are not stored in the repo):

```toml
[build]
  command = "python3 scripts/gen-sites.py && bash scripts/fetch-ytdlp.sh"
```

Function timeouts are 26s per function (`[functions.timeout]` in `netlify.toml`).

## Platform status

Works live (verified): YouTube (360p with audio from server IPs — YouTube withholds higher qualities from datacenter IPs), TikTok, Instagram, Facebook, X/Twitter (via the public syndication endpoint).
Blocked server-side (no free fix — needs a residential proxy or logged-in accounts): Reddit, Vimeo, Dailymotion.
